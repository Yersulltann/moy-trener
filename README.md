# Мой тренер

PWA-трекер: зал, бассейн, питание, расписание, прогресс.

- Запуск локально: `npm run dev`
- Выложить обновление на GitHub Pages: `npm run deploy`
- Программа, продукты, расписание: `src/data/`

Фото упражнений: [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (public domain).
